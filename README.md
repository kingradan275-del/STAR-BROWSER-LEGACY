# STAR-BROWSER-LEGACY
STAR BROWSER LEGACY 1.0 | یک مرورگر وب سبک، سریع و مستقل برای اندروید که با هدف فراهم‌کردن تجربه‌ای ساده و کاربردی از وب‌گردی، به‌ویژه روی گوشی‌ها و دستگاه‌های اندرویدی قدیمی و کم‌توان طراحی شده است. ساخته‌شده با Java، XML و Android WebView، با هدف پشتیبانی از Android 4.2.2 به بالا.
